Include with upload_overlay_title, then call ProjectUploadSubmit.attach(form, {alertBox, beforeSubmit}). A native submit cannot report progress, and when the browser stopped one the page stayed up under an overlay that nothing took down. The body is new FormData(form): the same fields, in the same order, that a native submit sends, so the views see no difference apart from the X-Requested-With header (see _redirect_as_json_for_xhr). {% endcomment %}
