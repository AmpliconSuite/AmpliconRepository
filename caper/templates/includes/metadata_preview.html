{% comment %} Client-side preview of an uploaded sample-metadata sheet, shared by the project creation and project edit pages. Included rather than shipped as a static .js file on purpose: static assets are served from S3 in dev/prod (settings.USE_S3) and are only published by a manual `sync_static_to_s3.sh` run, so a new static file 404s until someone remembers to sync it. A template include is deployed with the code. Depends on SheetJS, which both host pages already load. SheetJS parses CSV and TSV as well as XLSX, which matters: the hand-rolled `line.split(',')` this replaces mis-splits any quoted field containing the delimiter, and real clinical sheets are full of them (PCAWG has values like "Adenocarcinoma, NOS"). The host page drives this via MetadataPreview.attach(); see the two call sites. {% endcomment %}
