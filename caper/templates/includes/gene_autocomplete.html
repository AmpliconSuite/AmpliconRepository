{% comment %} Gene autocomplete for a search box. header.html includes this once on every page and attaches it to each search form's gene box (the header's Advanced modal, and the results page's own copy of that form); other boxes call GeneAutocomplete.attach(input, {active: function () { return true; }}). It completes the term being typed -- the text after the last & or | -- from /api/gene-suggest/, which starts suggesting at 3 characters and before that offers only an exact name (AR, ALK). Each entry shows the gene's NCBI symbol, full name and Gene ID, and the name the text matched when that is not the symbol (an alias, a former symbol, AmpliconSuite's own name for it, with the builds it is used in). Choosing one writes the symbol into the box and submits the form. A term holding * is a wildcard and gets no suggestions. {% endcomment %}
