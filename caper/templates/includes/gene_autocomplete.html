{% comment %} Gene autocomplete for a search box, and the gene chips of the Advanced search form. header.html includes this once on every page and sets up each search form's gene box (the header's Advanced modal, and the results page's own copy of that form); other boxes call GeneAutocomplete.attach(input, {active: function () { return true; }}). It completes the term being typed -- the text after the last & or | -- from /api/gene-suggest/, which starts suggesting at 3 characters and before that offers only an exact name (AR, ALK). Each entry shows the gene's NCBI symbol, full name and Gene ID, and the name the text matched when that is not the symbol (an alias, a former symbol, AmpliconSuite's own name for it, with the builds it is used in). In a plain box, choosing one writes the symbol into the box and submits the form; in the chip box it adds a chip, so a second gene can follow. Gene search has no wildcards; a term holding * gets no suggestions. {% endcomment %}
