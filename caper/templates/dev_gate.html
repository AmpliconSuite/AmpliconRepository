{% comment %} Development-server landing gate. See caper/caper/dev_gate.py. Standalone on purpose: this does NOT extend base.html. It is rendered by middleware sitting above sessions, auth, MongoDB and the Mezzanine page machinery, so it can use no context processor, no staticfiles tag and no site navigation. Everything it needs -- styles and the wordmark -- is inlined, which also means the gate cannot break from a static-deploy problem. The palette is the deployed site's own: #414042 wordmark charcoal, #1f66d0 action blue, #f0a202 amber (the same signal colour as the yellow dev banner in includes/header.html), and the site's blue-biased greys. A lost visitor has to recognise the right project on the wrong server, so a page that looked foreign would make the confusion worse. Light-only, deliberately: it ships into a light-only Bootstrap 4 site. The passphrase is not a secret, but it does not belong on the page that asks for it -- that would gate nobody. It is in README.md, AGENTS.md and the wiki page linked below. {% endcomment %} Development server | AmpliconRepository
